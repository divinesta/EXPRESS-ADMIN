Features

Everything you need to
manage your data.

Drop in Express Admin and get a production-ready operations UI. No weeks of custom dashboard work.

Schema Introspection

Reads your Prisma schema automatically. Models, relations, enums, and field constraints are all detected and mapped to UI components.

Auth & Permissions

Built-in role-based access control. Define who can view, create, update, or delete records on each model with simple config.

Auto CRUD API

Every registered model gets a complete REST API: list, create, read, update, delete with pagination, filtering, and sorting out of the box.

Operations UI

A fully responsive admin interface with search, filters, inline editing, bulk actions, and real-time updates. Ready for your ops team on day one.

How it works

Three steps to your admin panel.

From zero to a production admin UI in under five minutes. No code generation, no scaffolding.

1

Point at your Prisma schema

Express Admin reads your existing schema.prisma file. No migration, no config files to write.

2

Register your models

Choose which models to expose. Customize field display, validation rules, and access permissions per model.

3

Mount & ship

Mount the admin router on any path. Your team gets a polished UI and API instantly. Deploy anywhere Express runs.

Quick setup

Up and running in minutes, not days.

Install the package, point it at your Prisma client, and mount it. That's the entire integration.

  • Works with any existing Express app
  • Zero config required — sensible defaults
  • Full TypeScript support with autocomplete
  • Compatible with Bun and Node.js runtimes
server.ts 
import express from 'express'
import { PrismaClient } from '@prisma/client'
import { expressAdmin } from 'express-admin'

const app = express()
const prisma = new PrismaClient()

// Create the admin panel
const admin = expressAdmin({
  prisma,
  models: ['User', 'Post', 'Order'],
  auth: { provider: 'session' }
})

// Mount on any path
app.use('/admin', admin)

app.listen(3000)
