# Quickstart

Get `/admin` running against *your* Express app and *your* Prisma schema.

## Requirements

- Node.js `^20.19 \|\| ^22.12 \|\| >=24` or Bun `>=1.3`
- Express 4 or 5
- Prisma and `@prisma/client` **7.5.x**
- A generated Prisma Client and a `schema.prisma` file on disk

Keep `prisma`, `@prisma/client`, and `prisma-express-admin` on the same 7.5.x line. Prisma internals are version-coupled. See [Prisma versions](/limits/prisma).

## Install

```bash
npm install prisma-express-admin express @prisma/client
npm install --save-dev prisma
```

Generate your client as you already do. This package never uses a client generated by the library repository.

## Mount

```ts
import express from "express";
import { createAdmin } from "prisma-express-admin";
import { prisma } from "./prisma.js";

const app = express();

const admin = createAdmin({
  prisma,
  databaseProvider: "postgresql",
  auth: {
    getCurrentUser: async (req) => {
      const user = await getAdminUserFromRequest(req);
      return user
        ? {
            id: user.id,
            email: user.email,
            role: user.role,
            isSuperAdmin: user.isSuperAdmin,
          }
        : null;
    },
  },
});

admin
  .register("User")
  .register("Post", { listDisplay: ["title", "published", "createdAt"] });

await admin.mount(app);

app.listen(3000);
```

Open `http://localhost:3000/admin`.

`getCurrentUser` must return `{ id, email, role, isSuperAdmin }` or `null`. A partial object is treated as unauthenticated.

## Three things that fail in production

1. **Prisma range.** 7.5.x only. Upgrade Prisma and this package together.
2. **Schema file.** At mount the library reads `prisma/schema.prisma` relative to `process.cwd()`. Include that file in the deploy artifact, or pass `schemaPath`.
3. **Identity.** There is no development backdoor in the published package. If `getCurrentUser` returns `null`, `/admin/api/*` is 401 — including `/admin/api/schema`.

```ts
createAdmin({
  prisma,
  schemaPath: "db/schema.prisma",
  auth: { getCurrentUser },
});
```
