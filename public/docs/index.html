Prisma Express AdminRegister your models. The schema is the source of truth.

A Django-style admin panel for Express and Prisma. You already wrote the data model — this library turns it into a guarded operations UI.

Getting started
Wire it into your app

  • Schema-driven

    Reads your schema.prisma at mount. No second admin schema. register("User") is enough to get a working list and form.

  • You bring the identity

    There is no login page. Plug getCurrentUser into your session, JWT, or API key. The admin never invents users.

  • Scope is first-class

    A scope() function is applied to list, read, update, delete, relation picks, and custom actions. Ada cannot see Grace's tenant by guessing an ID.

  • Safe by default

    Password-like fields stay hidden. Unknown write keys are rejected. The schema endpoint sits behind the same auth as CRUD.
